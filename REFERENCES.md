# Источники для модели истребителя — ЛР1

Подборка от 26.10.2026: три научные журнальные статьи с конкретными параметрами F-16. В `1.md` требуется пять статей с высокой цитируемостью. Эта подборка пока не закрывает требование: нужны ещё две статьи и проверка цитируемости. Google Scholar оказался недоступен через используемый инструмент; число цитирований в нём не подтверждено. Представленные работы отобраны по наличию проверяемых числовых данных, а не по доказанной высокой цитируемости.

## Предлагаемый исходный набор полей

Предложение для последующей реализации, а не уже внесённое изменение `models.py`:

| Поле | Тип Python | Пример | Происхождение |
| --- | --- | --- | --- |
| `id` | `int` | `1` | Идентификатор, назначаемый приложением |
| `name` | `str` | `"F-16 Fighting Falcon"` | Статья 1, раздел 2 |
| `engine_count` | `int` | `1` | Статья 1, раздел 2 |
| `mass_kg` | `float` | `9295.44` | Статья 2, таблица 1 |
| `wingspan_m` | `float` | `9.144` | Статья 2, таблица 1 |
| `wing_area_m2` | `float` | `27.87` | Статья 2, таблица 1 |
| `mean_aerodynamic_chord_m` | `float` | `3.45` | Статья 2, таблица 1 |

Это семь полей с тремя типами данных; в задании требуется минимум шесть полей с разными типами, наличие `bool` отдельно не предписано. Четыре числовых параметра массы и геометрии взяты согласованно из одной таблицы. В описании записи следует указать, что это параметры расчётной модели F-16 из статьи 2.

Массы 9210, 9295.44 и 9295.4 кг нужно сохранять вместе со ссылками на соответствующие исследования, а не усреднять. Размах 9.144 м — значение из рассматриваемых моделей; его не следует выдавать за универсальную характеристику всех модификаций F-16.

Для существующего поля `speed` сначала нужно определить смысл и единицы. Скорость полёта в конкретном опыте не является максимальной скоростью самолёта. Проверенные здесь таблицы не обосновывают поля `max_speed`, `length` или `country`.

## Связь с CRUD

Статьи обосновывают выбор характеристик сущности. Создание, чтение, обновление и удаление записей каталога — логика приложения по заданию ЛР1; исследовательские алгоритмы управления самолётом реализовывать для этого не требуется. Как проектное решение предлагается проверять положительность размеров, массы и числа двигателей и сохранять единицы измерения в названиях полей.
